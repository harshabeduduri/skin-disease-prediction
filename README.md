# Skin Disease Prediction System

A Python educational project that maps user-entered symptoms to possible skin conditions using predefined decision logic.

## Overview

The program accepts symptom-related input and uses rules in the application to return a possible condition and basic informational suggestions. It demonstrates input handling and conditional decision-making.

## Technology

- Python

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/harshabeduduri/skin-disease-prediction.git
   cd skin-disease-prediction
   ```

2. Run the program:
   ```bash
   python skin_prediction.py
   ```

## Current functionality

- Accepts symptom information from the user
- Applies predefined decision logic
- Displays a possible result and general suggestions

## Important medical disclaimer

This project is for educational demonstration only. It is **not a medical diagnostic tool** and must not be used to diagnose, treat, or rule out a health condition. For medical concerns, consult a qualified healthcare professional.
