# Skin Disease Prediction System

A basic Python application that predicts possible skin conditions based on user input symptoms.

## Description
This project demonstrates simple decision logic to map symptoms to possible conditions and provide basic remedial suggestions. It represents an applied use of beginner-level AIML concepts.

## Technologies Used
- Python

## How to Run
1. Run the program:
   python skin_prediction.py

## Use Case
Educational project to understand basic prediction logic and user input handling.
